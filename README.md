# Website RAG Assistant

A simple Retrieval-Augmented Generation (RAG) application that crawls a website, converts the website content into LangChain documents, splits the content into chunks, creates embeddings, stores them in an in-memory vector store, retrieves relevant context, and generates answers using an OpenAI language model.

## Project Stack

- Backend: FastAPI
- Frontend: React + Vite
- Web Crawler: Apify Website Content Crawler
- RAG Framework: LangChain
- Embeddings: OpenAI Embeddings
- Vector Store: InMemoryVectorStore
- LLM: OpenAI via LangChain

## Prerequisites

Make sure the following are installed:

- Python 3.x
- Node.js
- npm
- OpenAI API key
- Apify API token

Check installation:

```powershell
python --version

```

## 1. Configure Environment Variables

Inside the `backend` folder, create a `.env` file.

Add:

```env
OPENAI_API_KEY=your_openai_api_key
APIFY_TOKEN=your_apify_token
```

Do not upload the `.env` file to GitHub.

Add the following to `.gitignore`:

```text
.env
__pycache__/
node_modules/
```

## 2. Install Backend Dependencies

Open a terminal from the project root and move to the backend folder:

```powershell
cd backend
```

Install required packages:

```powershell
python -m pip install -r requirements.txt
```

If you do not yet have a `requirements.txt`, install the main packages manually:

```powershell
python -m pip install fastapi uvicorn python-dotenv apify-client langchain-core langchain-openai langchain-text-splitters numpy
```

A sample `requirements.txt` can contain:

```text

python-dotenv
```

## 7. Use the Application

### Step 1: Enter a Website URL

Example:

```text
https://docs.langchain.com/oss/python/langchain/quickstart
```

### Step 2: Click `Crawl Website`

The application will:

1. Send the URL from React to FastAPI.
2. Start the Apify Website Content Crawler.
3. Retrieve the dataset generated by the same Apify run.
4. Convert crawled content into LangChain `Document` objects.
5. Split documents into smaller chunks.
6. Generate OpenAI embeddings.
7. Store the embeddings in `InMemoryVectorStore`.
8. Create a retriever for similarity search.

After a successful crawl, the frontend can display something similar to:

```text
1 page(s) crawled, 12 chunks indexed successfully
```

### Step 3: Enter a Question

Example:

```text
How do I create an agent using LangChain?
```

### Step 4: Click `Ask AI`

The application will:

1. Convert the question into an embedding.
2. Retrieve the most relevant chunks from the vector store.
3. Build context from those chunks.
4. Send the context and question to the LLM.
5. Return the generated answer.
6. Display source URLs in the frontend.

## Important Notes

### In-Memory Vector Store

The project currently uses:

```python
InMemoryVectorStore
```

This means indexed website data is stored only in memory.

If the FastAPI backend is stopped or restarted, the vector store is cleared.

You must click `Crawl Website` again before asking questions.

For a production version, consider using a persistent vector database such as:

- Chroma
- FAISS
- Pinecone
- Qdrant
- Weaviate

### CORS

The React frontend and FastAPI backend run on different ports.

For local development, FastAPI must allow the frontend origin.

Example:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
        "http://127.0.0.1:5173"
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### Frontend API URL

In `frontend/src/api.js`, the backend URL should point to FastAPI:

```javascript
const API_URL = "http://127.0.0.1:8000";
```

## Troubleshooting

### `uvicorn` is not recognized

Use:

```powershell
python -m uvicorn main:app --reload
```

instead of:

```powershell
uvicorn main:app --reload
```

### `Failed to fetch`

Check:

- FastAPI is running.
- React is running.
- CORS is configured correctly.
- `api.js` points to the correct backend URL.

### `OPTIONS /crawl 400 Bad Request`

This usually indicates a CORS configuration issue.

Verify the frontend origin is present in `allow_origins`.

### `'Run' object is not subscriptable`

With newer versions of the Apify Python client, use:

```python
dataset_id = run.default_dataset_id
```

instead of:

```python
dataset_id = run["defaultDatasetId"]
```

### `cosine_similarity requires numpy`

Install NumPy:

```powershell
python -m pip install numpy
```

### Website crawls but answer is not found

Check:

- Whether Apify extracted useful page text.
- How many documents were created.
- How many chunks were created.
- Whether retrieved chunks are relevant.
- Whether the chosen page actually contains information related to the question.

Useful backend debug output:

```python
print("Documents created:", len(documents))
print("Chunks created:", len(chunks))
print("Retrieved chunks:", len(docs))
```
